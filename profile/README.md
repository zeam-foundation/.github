## Overview

ZEAM is a memory-first substrate architecture. The patent portfolio covers:

- Distributed memory-mesh coordination
- Deterministic (non-generative) AI execution
- Genesis-anchored governance
- Layered identity and privacy systems
- Memory-pressure-based coordination
- Non-token economic models
