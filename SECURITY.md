# Security Policy

Default policy for repositories in this organization.

## Reporting

**info@zeamlabs.com** — put `SECURITY` in the subject. Expect an acknowledgement within 72 hours and
a straight answer on whether we can fix it and when.

Report privately, rather than in a public issue, anything that could expose private data. Everything
else is fine in the open. There is no bug bounty; credit by name or handle on request.

## What is here

This organization holds records, not running code: patent applications in
[zeam-ip](https://github.com/zeam-foundation/zeam-ip) and formation documents in
[ZEAM-Foundation-Corporate-Docs](https://github.com/zeam-foundation/ZEAM-Foundation-Corporate-Docs).
There is no service to attack and no key material in scope.

What is worth reporting here: a filing published in error, a document containing information that
should not be public, or an application number, date or title that does not match the record. Errors
in a published legal record matter to us as much as a software defect would.

## Software and services

ZEAM Labs, LLC operates everything that runs and licenses the technology commercially. For the client
tooling, the metered endpoint at `mcp.zeamprism.com`, or anything involving keys, funds or payment
verification, see the [ZEAM Labs security policy](https://github.com/zeam-labs/.github/blob/main/SECURITY.md).
Same address either way.
